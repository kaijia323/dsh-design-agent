# 这里是 AC9 的验收物证，不是插件源码

`order-list.tsx` 是 **AC9（落地到项目）** 的落地产物：

独立验收者在真实界面里点「落地到项目」→ 拿到可复制的落地指令 → 交给一个独立 agent →
由它把设计稿 `order-list` 按项目技术栈转成 React 组件写出来。它证明的是
「**设计 → 代码**」这条链路真的通，而不是只产出一段提示词。

**归档位置说明**：验收时它写在 `src/generated/order-list/index.tsx`。
验收后移到这里，原因是——在本插件仓库里 **`src/` 就是插件的发布源码树**
（`package.json` 的 `files`/`exports` 指向它），把一份业务页面放在那儿会让人误以为它是插件代码，
而且理论上会跟着插件一起被发布。物证应该跟证据在一起。

**本插件的真正源码**在 `client.js`（客户端半）、`index.js` 与 `src/host/`（host 半）。

> 顺带记一条由这次验收暴露的产品债：`prompts/design-handoff.md` 让人"看 `src/` 的现有约定"，
> 在插件型仓库里会失灵（`src/` 下只有后端代码）。已登记为 SPEC 的 follow_up **F8**。
